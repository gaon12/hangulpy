## 참고

- `__version__`은 설치된 `hangulpy` 배포판의 버전 문자열입니다.
- 순서대로 읽고 싶다면 [소개](index), [설치하기](installation), [빠른 시작](quickstart) 순서로 보면 됩니다.
- `chosungIncludes`, `notallowempty`, `allowDoubleConsonant`는 v1.5에서 제거됩니다. [v1.5 마이그레이션](migration-v1-5)을 확인하세요.
- 버전별 변경점은 [v1.4.0 릴리즈 노트](releases/v1-4-0)에서 확인할 수 있습니다.
