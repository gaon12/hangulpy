## 설치

```bash
pip install hangulpy
```

## Python 지원 범위

v1.4.x의 패키지 메타데이터는 Python 3.8 이상을 허용하며, 다음 기준으로
호환성을 검증합니다.

| Python | v1.4.x 지원 수준 |
| --- | --- |
| 3.8~3.13 | 지원, 필수 CI 테스트 |
| 3.14 | 완전 지원, 필수 CI 테스트와 배포 패키지 검증 |
| 3.15 프리릴리스 | 최선 지원, 실패를 허용하는 선행 CI 테스트 |

Python 3.15 프리릴리스 검증은 새 인터프리터의 회귀를 일찍 찾기 위한 것입니다.
정식 3.15가 출시되고 필수 CI를 통과하기 전까지는 완전 지원을 의미하지 않습니다.

v1.5부터는 Python 3.11 이상이 필요합니다. 이전 Python을 유지해야 한다면
마지막 호환 계열을 명시해서 설치할 수 있습니다.

```bash
python -m pip install "hangulpy<1.5"
```

최소 버전 변경의 배경은 [v1.5 마이그레이션](migration-v1-5)에서 확인할 수
있습니다.

## 업그레이드

```bash
pip install -U hangulpy
```

## 가져오기

```python
from hangulpy import josa, romanize
```

## 개발용 설치

저장소를 직접 열고 테스트까지 실행하려면 아래처럼 설치하면 됩니다.

```bash
pip install -e .[dev]
python -m pytest -o addopts=''
```
