## 내부 모듈 정리

공개 함수 목록(`hangulpy.__all__`)은 변하지 않았습니다. 내부 모듈 경로만
정리했습니다.

- `hangulpy.hangul_split` 모듈을 `hangulpy.hangul_decompose`로 합쳤습니다.
  같은 이름의 `hangul_split` 함수와 모듈이 패키지 속성 자리에서 충돌해
  정적 분석 도구가 함수를 모듈로 잘못 해석하는 문제를 제거했습니다.
  `from hangulpy import hangul_split, split_hangul_string` 사용법은 그대로
  동작하며, `import hangulpy.hangul_split`처럼 모듈 경로를 직접 쓰던 코드만
  `hangulpy.hangul_decompose`로 바꾸면 됩니다.
- `hangulpy.is_hangul` 모듈은 `hangulpy.utils` 구현을 다시보내는 얇은
  호환 계층으로 정리했습니다.
- 런타임 불리언 검사 도우미를 `hangulpy._deprecated`에서
  `hangulpy._validation`으로 옮겼습니다. 공개 API는 아닙니다.

## 품질 게이트

- Pyright 검사 범위가 패키지에서 테스트까지 넓어졌습니다. 테스트 파일은
  pytest 관용구와 의도적 타입 오류 검증을 위해 basic 모드로 검사합니다.
- 커버리지 하한선(85%) 선언을 `[tool.coverage.report]` 한 곳으로 모았습니다.
- 모든 공개 모듈이 정의한 함수·클래스를 `__all__`에보내는지 검증하는
  테스트를 추가하고, 수동으로 돌리던 `generate_init_imports.py` 스크립트를
  제거했습니다.

## 배포 메타데이터

프로젝트 성숙도 분류자를 `Development Status :: 5 - Production/Stable`로
올렸습니다.
