## Python 3.11 이상 필요

v1.5의 최소 Python 버전은 3.11입니다. 3.11~3.14를 필수 CI에서 검증하며,
3.15 프리릴리스는 실패를 허용하는 별도 작업에서 확인합니다.
Python 3.8~3.10을 유지하는 환경에서는 v1.4.x를 사용하세요.

```bash
python -m pip install "hangulpy<1.5"
```

## 제거된 호환 API

v1.4에서 경고하던 다음 이름은 v1.5에서 제거했습니다.

| 제거된 이름 | 대체 이름 |
| --- | --- |
| `chosungIncludes` | `chosung_includes` |
| `notallowempty` | `not_allow_empty` |
| `allowDoubleConsonant` | `allow_double_consonant` |

구식 함수 이름은 더 이상 가져올 수 없고, 구식 키워드는 `TypeError`를 발생시킵니다.
검색·키보드 옵션은 `bool`을 받으며 기본값은 `False`입니다. 명시적인 `None`이나
정수 대신 `True`/`False`를 사용하세요.

```python
from hangulpy import chosung_includes, enko, hangul_contains

chosung_includes("사과", "ㅅㄱ")
hangul_contains("사과", "", not_allow_empty=True)
enko("rrk", allow_double_consonant=True)
```

`hangul_search`, `hangul_search_all`, `HangulSearcher`의 검색 메서드에도 같은
검색 키워드를 적용하세요. 키보드 키워드는 `enko`, `autofix`,
`convert_qwerty_to_hangul`에서 동일합니다.

기존 경고 필터가 가져오는 `HangulpyDeprecationWarning` 클래스는 유지합니다.
이 클래스를 가져올 수 있다는 사실이 제거된 API 호출을 허용한다는 뜻은 아닙니다.

## 달라지는 결과

- 호환 자모 검색·치환은 실제 조합된 원문 구간을 사용하며, 기본 매치는 원문에서
  겹치지 않습니다. 결합 문자가 재정렬되는 경우 결합 문자 묶음을 함께 보존합니다.
- 꽃잎·솜이불·색연필의 ㄴ 첨가를 처리하고, 금요일의 로마자 표기에서 불필요한
  `n`을 제거했습니다. 임의의 형태소 경계를 모두 분석하는 기능은 아닙니다.
- `jarip_noun`의 진열·분열·기념·사례·요령 결과를 바로잡았습니다.
- 큰 단위 구는 숫자 9와 같은 글자를 사용합니다. `일구`는 자동으로 복원하고,
  `십구`의 큰 단위 해석은 `large_unit_gu=True`로 지정합니다.
  [큰 수의 중의성](api/conversions/hangul-to-number)을 확인하세요.
