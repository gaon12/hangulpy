v1.4는 Python 명명 규칙에 맞춘 새 이름을 도입하면서 기존 호출을 한 릴리즈 동안
호환합니다. 아래 세 이름은 사용 시 `DeprecationWarning`을 발생시키며 **v1.5에서
제거될 예정**입니다.

| 제거 예정 이름 | 대체 이름 |
| --- | --- |
| `chosungIncludes` | `chosung_includes` |
| `notallowempty` | `not_allow_empty` |
| `allowDoubleConsonant` | `allow_double_consonant` |

## 검색 옵션

`hangul_contains`, `hangul_search`, `hangul_search_all`과 `HangulSearcher` 메서드의
호출을 다음처럼 바꿉니다.

```python
from hangulpy import hangul_contains

hangul_contains("사과", "", not_allow_empty=True)
```

## 키보드 변환 옵션

`enko`, `autofix`, `convert_qwerty_to_hangul`에서는 snake_case 옵션을 사용합니다.

```python
from hangulpy import enko

enko("rrk", allow_double_consonant=True)
```

새 이름과 제거 예정 이름을 한 호출에서 함께 넘기면 `TypeError`가 발생합니다.

## 경고 표시와 필터링

호환 API는 Python 표준 `warnings.warn`과 `DeprecationWarning`의 하위 클래스인
`HangulpyDeprecationWarning`을 사용합니다. 따라서 일반적인 Python 경고 필터,
`-W` 옵션, `PYTHONWARNINGS` 환경 변수로 표시 여부를 제어할 수 있습니다.

```python
import warnings

from hangulpy import HangulpyDeprecationWarning

# hangulpy의 제거 예정 API 경고만 숨깁니다.
warnings.filterwarnings("ignore", category=HangulpyDeprecationWarning)
```

테스트나 마이그레이션 점검 중에는 같은 필터의 동작을 `"error"`로 바꾸면 경고를
예외로 처리할 수 있습니다.
